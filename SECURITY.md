# Security Policy

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/mkutlak/home-assistant-mazda/security/advisories/new) on this repository. Do not open a public issue.

Only the `main` branch is supported. If the problem is also in the upstream integration ([fano0001/home-assistant-mazda](https://github.com/fano0001/home-assistant-mazda)), say so in the report and it will be forwarded there.
